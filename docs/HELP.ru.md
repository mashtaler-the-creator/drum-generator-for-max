# Хелп: как этим пользоваться

Генератор барабанных MIDI-партий. Библиотека паттернов по стилям (jungle,
dnb, techno) + движок, который делает из паттерна живую партию: свинг,
динамика хэтов, ghost-ноты, филлы, человеческий тайминг. На выходе —
`.mid` файл, который перетаскиваешь на драм-рек в Ableton.

---

## Шаг 0. Что нужно

- Node.js 18+ (`node --version` для проверки)
- Ableton Live (любой, где есть Drum Rack)
- Этот репозиторий локально

Установка не нужна — зависимостей нет. Склонировал и работаешь.

## Шаг 1. Собрать драм-рек (один раз, ~15 минут)

1. MIDI-трек → перетащи на него пустой **Drum Rack** (Instruments → Drum Rack)
2. Раскидай сэмплы по пэдам строго по нотам:

   | Пэд | Звук |
   |-----|------|
   | C1  | кик (короткий, панчевый) |
   | C#1 | римшот |
   | D1  | снейр (с телом и щелчком) |
   | D#1 | клэп |
   | F#1 | закрытый хэт |
   | A#1 | открытый хэт |
   | C#2 | крэш |
   | D#2 | райд |

3. **Choke для хэтов:** кнопка `I-O` на реке → колонка Choke → поставь `1`
   у закрытого И у открытого хэта
4. **Velocity в каждом пэде:** Simpler → Controls → крутилка `Vel` под
   Volume → 70-100%. Без этого динамика генератора сплющится — это самая
   важная настройка
5. Сохрани рек (правый клик по титульной плашке → Save)

Томы/конги/шейкеры — опционально, ноты в `drum-rack-setup.md`. Добавляй,
когда начнёшь использовать паттерны с этими ролями.

## Шаг 2. Сгенерировать партию (каждый раз, ~1 минута)

```bash
cd путь/к/m4l-drum-generator

# посмотреть список паттернов
node tools/render.js

# сгенерировать 8 тактов jungle на 172 BPM
node tools/render.js --pattern jungle_amen_01 --bars 8 --bpm 172 \
    --preset breaks --out out/beat.mid
```

Перетащи `out/beat.mid` из Finder на трек с драм-реком. Готово.

## Шаг 3. Крутилки

| Флаг | Что делает | Пример |
|------|-----------|--------|
| `--preset` | характер: `breaks` (живой jungle), `tight` (аккуратный сешн-барабанщик), `machine` (робот, для техно) | `--preset breaks` |
| `--bars` | длина в тактах | `--bars 16` |
| `--bpm` | темп файла | `--bpm 174` |
| `--density` | плотность 0..1: меньше = реже неакцентные ноты | `--density 0.8` |
| `--ghosts` | вероятность ghost-нот 0..1 | `--ghosts 0.1` |
| `--seed` | зерно рандома: с ним результат повторяется, без него каждый запуск — новая вариация | `--seed 42` |
| `--out` | куда писать файл | `--out out/beat.mid` |

Тонкая настройка поверх пресета: `--humanize <тики>`, `--hat-cycle <0..1>`,
`--backbeat <буст>`, `--vel-jitter <0..7>`.

Рабочий цикл простой: генерируешь без `--seed`, слушаешь; не зашло —
запускаешь ещё раз, получаешь другой вариант. Зашло — переносишь в проект.

## Шаг 4. Добавить свои паттерны

1. Скопируй любой файл из `patterns/<стиль>/` и правь
2. Формат: массивы velocity по ролям, 0 = тишина, длина = bars × stepsPerBar
3. Ориентиры по velocity: основные снейры 100-115, хэты 60-95, всё ниже
   70 — территория гостов. Velocity ≥ 90 — акцент, он не выпадает при
   низкой density
4. Тег `"fill"` в `tags` делает паттерн филлом — движок сам подставляет
   его каждые N тактов
5. Проверка: `npm run validate`

## Если что-то не так

- **Всё звучит одинаково громко** → шаг 1.4, Vel в Simpler
- **Открытый хэт гудит поверх закрытого** → шаг 1.3, choke-группа
- **Партия слишком рваная** → подними `--density` до 1.0 или возьми `--preset tight`
- **Слишком роботно** → `--preset breaks` или подними `--humanize`
- **Ошибка "pattern not found"** → `node tools/render.js` без флагов покажет точные id
